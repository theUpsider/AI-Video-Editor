- AC-1 Probe the current environment for workflow tools, available models, subagents, worktree isolation, permissions, hooks, network, browser tools, CPU/RAM, and accelerator access — FAIL: The accelerator verdict contradicts the requirement's own AC-1 edge case and nothing tests it. Requirement § Edge cases (docs/requirements/AVE-REQ-094-capability-aware-native-dynamic-workflows.md:42-43): "the probe prints `accelerator: none (no device)` whenever no device node exists and `nvidia-smi` reports no GPU". Code (scripts/probe-environment.sh:46, :56-58): `gpu="$(first nvidia-smi --query-gpu=... )"` captures whatever nvidia-smi writes to standard output, never examines its exit status, and feeds `$gpu` into `evidence`, so any text on stdout becomes `accelerator: present (...)`; the comment on line 55 ("The verdict counts devices only") describes behavior the code does not have. Demonstration in the clone's container (`./scripts/dev-container.sh bash -c ...`, fake `nvidia-smi` first on PATH, `AVE_PROBE_DEV_DIR` pointing at an empty directory, `--offline`): fake A replaying nvidia-smi's driver-missing diagnostic on stdout with exit 9 -> `accelerator: present (NVIDIA-SMI has failed because it couldn't communicate with the NVIDIA driver. ...)`; fake B replaying `No devices were found` with exit 6 -> `accelerator: present (No devices were found)`; fake C (empty stdout, exit 0) -> `accelerator: none (no device)`. In both A and B the device lists read `none`, i.e. exactly the edge-case configuration (nvidia-smi installed, no device: a CI image or a container run without `--gpus`), and the probe claims an accelerator. The consumer of the verdict is docs/ENVIRONMENT_CAPABILITIES.md:143, which tells the human to treat `accelerator: present (...)` as the signal that a GPU host is ready, so this is a fake-capability claim path contrary to the product invariant that missing devices are reported gaps. Coverage: scripts/tests/test-probe-environment.sh hides `nvidia-smi` from PATH in every scenario (lines 218, 285, 380: `path_without nvidia-smi ...`) and no scenario places a fake nvidia-smi on PATH; the only accelerator checks are the no-nvidia-smi cases (lines 261-264) and the device-node case (line 281). Mutation in a /tmp copy: `if have nvidia-smi || [ -n "$evidence" ]; then` (verdict `present` whenever nvidia-smi is installed, regardless of devices) survived with PROBE TOTAL: pass=96 fail=0. The reviewer's AC-1 row and verification runs never exercise the nvidia-smi-present path, so the edge case is unevidenced and, as shown, unmet. Fix: in scripts/probe-environment.sh keep `nvidia-smi` output as evidence only when the command exits 0 and prints a GPU row (e.g. `if gpu="$(nvidia-smi --query-gpu=name,memory.total --format=csv,noheader 2>/dev/null | head -n 1)" && [ -n "$gpu" ]; then ... else gpu=""`), or let the verdict count device nodes only as the comment states; add suite scenarios with a fake `nvidia-smi` that (a) prints a diagnostic and exits non-zero with no device node -> `none (no device)`, and (b) prints a GPU row and exits 0 -> `present (<row>)`.
